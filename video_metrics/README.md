**CLI утилита для анализа кликбейтности YouTube видео.** Фильтрация, сортировка и формирование отчётов из CSV файлов.

## ✨ Возможности

| 🎯 | **Анализ кликбейтности** | CTR > 15% и удержание < 40% |
|---|--------------------------|----------------------------|
| 📁 | **Мультифайловая обработка** | Объединение нескольких CSV |
| 📊 | **Табличный вывод** | Красивое форматирование |
| 🔧 | **Расширяемая архитектура** | Лёгкое добавление новых отчётов |
| ✅ | **Покрытие тестами** | pytest + тесты критической логики |
| 🛡 | **Валидация данных** | Обработка ошибок и некорректных строк |

---

## 📋 Формат входных данных (CSV)

| Колонка | Тип | Описание | Обязательная |
|---------|-----|----------|--------------|
| `title` | str | 📹 **Название видео** | ✅ |
| `ctr` | float | 📈 **CTR** (кликабельность, %) | ✅ |
| `retention_rate` | float | 👁 **Удержание** (%) | ✅ |
| `views` | int | 👀 Просмотры | ❌ |
| `likes` | int | 👍 Лайки | ❌ |
| `avg_watch_time` | float | ⏱ Среднее время просмотра | ❌ |

### Пример CSV файла:
```csv
title,ctr,retention_rate,views,likes,avg_watch_time
Секрет который скрывают тимлиды,25.0,22,254000,8900,2.5
Как я спал по 4 часа и ничего не понял,22.5,28,128700,3150,3.1
Я бросил IT и стал фермером,18.2,35,45200,1240,4.2
```

🚀 Быстрый старт
1. Клонирование
bash
git clone <repository-url>
cd video_metrics



2. Установка зависимостей
bash
pip install -r requirements-dev.txt


3. Запуск анализа
bash
python cli.py --files stats1.csv stats2.csv --report clickbait
